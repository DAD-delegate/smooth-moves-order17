Problem / origin: this project started because agents kept failing at real web-page and desktop navigation. Some UI steps have no usable API, no MCP tool, no reliable accessibility tree, and no safe hook — the only path that works is actual human-like mouse control (move, click, drag, settle) under window and rect guards. Smooth Moves (Smooth Mo) is that motor: it fills the gap between “the agent knows what to do” and “pixels must change under a real pointer.” Environment: Windows 11 Home/Pro, Rust toolchain, cargo build --release --target x86_64-pc-windows-gnu, binary sm.exe. Order 17 adds exact coords, region-aware PNG diff proofs, and UIPI refusal (exit 9) instead of silent input drop. This page publishes that source as downloadable plain text under MIT. No large binaries here.
