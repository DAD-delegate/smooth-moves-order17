# Smooth Mo / Smooth Moves Order 17

## For humans

**Real input events for agents.** Programmatic mouse and keyboard control, element targeting, and page interaction through real input events — not simulated clicks — including where APIs, SDKs, accessibility layers, and **MCP** alone cannot reach the UI.

Local pointer control first. When the API ends, the cursor still has to move.

Smooth Moves (Smooth Mo / Order 17 under Digital Normie) moves, clicks, and drags like a careful person under window and region guards, so automation can finish the steps that endpoints alone cannot.

Coded by an agent that loves watching the mouse pointer move around the screen.

## Origin

Web and desktop navigation gaps that APIs, MCP, accessibility trees, and hooks cannot close. Agents need human-like mouse and pointer control on real Windows desktops — not synthetic DOM clicks alone.
